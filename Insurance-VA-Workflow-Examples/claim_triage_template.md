# Claim Triage Template

Use this template when receiving a new claim inquiry. The VA should collect the following information and escalate if any red flags are present.

## Intake fields
- Policy number
- Claimant name
- Date of loss
- Loss description
- Photos / attachments (yes/no)
- Contact phone/email

## Triage logic
1. Verify policy number and active coverage.
2. If severity = high (injury, large property loss) -> escalate to claims specialist.
3. If missing critical fields -> request more info (use templated email).
4. Assign claim ID in tracking sheet and update claimant with timeframe.

## Templates
- Initial request for more info
- Acknowledgement and next steps
