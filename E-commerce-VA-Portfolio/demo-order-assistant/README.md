# Demo Order Assistant (Python)

This is a tiny, dependency-free demo that shows how a VA can process an orders CSV and mark orders as fulfilled. It's intentionally minimal so you can adapt it to real integrations (APIs, webhooks, spreadsheets).

Files

- app.py — main script
- orders.csv — sample input

How to run

1. Clone this repo.
2. Run: python3 app.py
3. The script reads orders.csv and writes processed_orders.csv.
